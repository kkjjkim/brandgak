## 대표 원칙 (꼭 지킬 것)
1. **굳이 우리에게 해가 되는 내용은 적지 않는다.** 하자보수 기간(1년, 2~4주 등 어떤 숫자도), 보증, 잔금 보류, 계약 상대 구조, 수수료, "공사를 권하지 않습니다" 같은 스스로 발목 잡는 약속 금지.
2. **싸게 해 준다는 인상 금지.** 가격·할인·견적 비교·"더 싸게"·"절감" 단어를 홈·광고성 문구에서 쓰지 않는다.
3. 디자인은 단순하게, AI가 만든 티 나지 않게. 사진 한 장 크게, 문장은 짧게.
4. 실적은 **디자인드비가 직접 시공한 것만** 쓴다. 포트폴리오 PDF 19쪽 이후(MONCLER, Paul Smith, ARMANI, Burberry, Acne 등)는 대표·팀장의 이전 회사 경력이라 쓰지 않는다. CHICOR·JAJU는 설계만 했으므로 쓰지 않는다.

## 홈 (`/`) 새 구성 — 모바일 우선, 이 순서대로
1. **헤더**: 로고 "브랜드각", 메뉴(시공 사례 · 인사이트 · 상담), 오른쪽 버튼 "카톡 문의". 카카오 채널 주소는 `lib/site.ts`의 `kakaoUrl`(지금 빈 값). 빈 값이면 버튼을 "전화 문의"(tel:010-8533-0140)로 대신 보여준다.
2. **첫 화면**: Yellow Basket 사진 크게 + 사진 위 작은 캡션 "Yellow Basket 가로수길 · 시공 (주)디자인드비 · 2022".
   - 제목: **포트폴리오만 봐서는 감이 안 오시죠?**
   - 부제: 첫 상담에 사장님 가게로 그린 컨셉 한 장을 들고 갑니다. 얼마를 어디에 써야 후회가 없는지도 같이 봅니다.
   - 버튼1(주): **내 가게 컨셉 한 장 받기** → 폼으로 스크롤. 버튼2: **카톡으로 먼저 물어보기** (kakaoUrl 없으면 "전화로 먼저 물어보기").
   - 증거 줄(작게): 시공 (주)디자인드비 · Bath & Body Works · THE SIENA · Yellow Basket · Mofun / **직접 시공한 매장 8곳, 8평부터 32평까지** / 사업 계획 · 국가공인 경영지도사
   - "실내건축공사업 등록" 문구는 `site.showLicense`(기본 false) 뒤에 둔다. Aside가 KISCON 확인 후 켠다.
3. **첫 상담에 두 장**: 제목 "첫 상담에 두 장을 드립니다." 1) 컨셉 한 장 — 손님이 이 가게를 한 문장으로 기억하게. 이름·색·재료 방향까지. 2) 예산 한 장 — 정해 주신 예산 안에서 어디에 힘을 줄지. 아래 한 줄: "상담만 받고 끝내셔도 됩니다."
4. **시공 사례**: 위 8건 카드(사진·브랜드·장소·평수·연도). 제목 "사장님 가게 크기의 매장을, 백화점 기준으로." 카드 전체 보기 → `/portfolio` 페이지(같은 데이터).
5. **다른 점**: 제목 "시작하는 질문이 다릅니다." 세 줄 — 흔히 "몇 평이세요?" → 브랜드각 "어떤 손님이 오는 가게를 원하세요?" / 흔히 디자인 시안부터 → 손님이 올 이유 한 문장부터 / 흔히 공사만 → 예산과 자금 계획까지 경영지도사가 같이.
6. **예산 한 문장**: "예산은 정해 주시면 됩니다. 그 안에서 손님 눈에 닿는 곳에 힘을 줍니다."
7. **진행**: 상담 → 컨셉·예산 두 장 → 설계 → 시공 → 오픈 (각 한 줄, 기간·조건 숫자 쓰지 않기).
8. **자주 묻는 질문** (이것만): 상담 비용이 있나요? → 없습니다. / 작은 평수도 하나요? → 8평 매장도 지었습니다. 평수보다 어떤 가게인지가 먼저입니다. / 지방도 되나요? → 상담은 전국, 시공은 현장 지역과 협의합니다. / 브랜드 작업은 따로 비용이 드나요? → 시공을 맡기시면 컨셉과 이름 방향까지 함께 잡습니다. / 정책자금도 볼 수 있나요? → 경영지도사가 대상 여부를 같이 봅니다.
9. **신청 폼** 제목 "어떤 가게를 준비하세요?": 이름*, 연락처*, 업종(버튼: 카페 / 식당 / 뷰티 / 리테일 / 기타), 지역, 오픈 예정(버튼: 3개월 안 / 6개월 안 / 미정), 선택: 평수, 예산(큰 금액부터: 3억 이상 / 1~3억 / 5천~1억 / 5천 이하 / 아직 모름), "어떤 가게를 열고 싶으세요?"(자유 입력, 선택).
   - 동의 체크 2개, **기본 해제**: [필수] 개인정보 수집·이용 동의(보기), [필수] 상담 진행을 위한 시공사 제공 동의 — 제공받는 자 "(주)디자인드비 등 브랜드각 협력 시공사", 항목 이름·연락처·문의 내용, 목적 상담·견적, 보유 상담 종료 후 1년.
   - 버튼 "내 가게 컨셉 한 장 받기". 아래: "영업일 하루 안에 경영지도사가 직접 전화드립니다."
   - 기존 `/api/leads`(메일 대체 접수 포함)와 Turnstile·허니팟 유지. 새 필드(open_timing, dream, consent)는 message에 합쳐 보내 DB 스키마 변경 없이 동작하게.
10. **모바일 하단 고정 바**: 전화 | 카톡(없으면 문자) | 상담 신청.
